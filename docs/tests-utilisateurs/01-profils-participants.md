## Conseils

- Éviter les proches de l’équipe : ils connaissent déjà le projet.
- Varier les appareils : au moins un participant sur téléphone.
- Si possible, inclure une personne utilisant une aide technique (lecteur d’écran, zoom, clavier seul) :
  c’est le seul moyen de valider réellement l’accessibilité.
