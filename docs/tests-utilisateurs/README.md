Ce dossier sert à tester NIRD WORLD avec de vraies personnes, puis à consigner ce qui a été observé.

## Préparer une séance

- **Durée** : 45 minutes environ (5 min d’accueil, 30 min de tâches, 10 min de questionnaire).
- **Deux personnes côté projet** si possible : un animateur qui parle, un observateur qui note sans intervenir.
- **Matériel** : un ordinateur ou un téléphone, selon l’appareil habituel du participant ; le site
  <https://nird-world.vercel.app> ouvert dans une fenêtre de navigation privée, pour partir d’une page vierge
  (aucun diagnostic déjà enregistré).
- **Imprimer** une fiche d’observation et un questionnaire par participant, ou dupliquer les fichiers Markdown.

## Consentement et respect des participants

- Expliquer en une phrase : « Nous testons le site, pas vous. Il n’y a pas de bonne ou de mauvaise réponse. »
- Demander l’accord avant toute prise de notes ou enregistrement d’écran. Pour un mineur, obtenir aussi l’accord
  d’un responsable légal et de l’établissement.
- Ne noter **ni nom complet, ni adresse, ni établissement réel** : utiliser un code (`E1`, `E2`, `P1`, `P2`, `A1`).
- Pendant le diagnostic, le participant peut répondre pour un établissement fictif ou passer les questions.
  Les réponses restent dans le navigateur ; supprimer le diagnostic à la fin (page « Mes diagnostics »).
- Le participant peut arrêter à tout moment, sans avoir à se justifier.

## Règles d’intégrité

- Ne jamais inventer un participant, un temps, une citation ou une note.
- Une case non observée reste **vide** ou porte la mention « non observé ».
- Recopier les citations telles qu’elles ont été dites, entre guillemets.
- Distinguer ce que le participant **a fait** de ce qu’il **a dit** et de ce que l’observateur **interprète**.
